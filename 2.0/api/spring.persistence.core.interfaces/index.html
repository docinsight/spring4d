IListSession<T>

Represents list session which can be used to sync changes in the list with the database table. E.g. entities from the database can be fetched by using a TSession . After List Session is started, changes can be made in the list (add new entities, remove current entities, change entity properties, etc.). To persist these changes CommitListSession must be called. To clear changes history RollbackListSession must be called.
