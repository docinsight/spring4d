Definition

Unit:
Spring.Cryptography
Package:
Spring.Extensions

Represents a series of bytes in memory.

Delphi 
type TBuffer = record

Remarks

The TBuffer structure is actually a wrapper of a value of TBytes and provides some easy-going methods and properties.
