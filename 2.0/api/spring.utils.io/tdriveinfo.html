Definition

Unit:
Spring.Utils.IO
Package:
Spring.Extensions

Provides access to information on a drive.

Delphi 
type TDriveInfo = record

Remarks

Use the static TDriveInfo.GetDrives method to retrieve all drives of the computer.

Notes to Callers

Caller must use the IsReady property to check whether the drive is ready before accessing other members. Otherwise, an EIOException exception will be raised if it is not ready.
