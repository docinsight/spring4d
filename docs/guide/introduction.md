# Introduction

> [!NOTE]
> This is an unofficial documentation showcase for [Spring4D](https://spring4d.org), a modern, comprehensive code library for Delphi. It was built with a prerelease build of **DocInsight 2026.1**, which has not been publicly released yet.

This site currently publishes a generated API reference only. It demonstrates how DocInsight can build navigable reference documentation from real Delphi source code.

Start with the <xref:api/Spring.Collections/IList`1> interface as an example.
